# DLX Virtual Machine

The CoCo compiler targets the **DLX processor**, a RISC-style educational
instruction set architecture with a software emulator written in Java.

## Registers

32 general-purpose registers (R0–R31):

| Register | Purpose |
|----------|---------|
| R0 | Hardwired to 0 |
| R1–R29 | General purpose (configurable: 1 to 24 available) |
| R30 | Stack pointer (initialized to MEM_SIZE - 1) |
| R31 | Return address (set by BSR/JSR, used by RET) |

## Memory

10,000 words (40 KB), word-addressable. Instructions and data share the
same memory space.

Memory is accessed via load/store instructions with byte addressing (address
is divided by 4 internally for word alignment).

## Instruction Formats

DLX uses a fixed 32-bit instruction word with three formats:

### F1: Immediate Format (32 bits)
```
| opcode (6) | a (5) | b (5) | immediate (16) |
```
Used for: immediate arithmetic, branches, load/store with offset

### F2: Register Format (32 bits)
```
| opcode (6) | a (5) | b (5) | c (5) | unused (11) |
```
Used for: register-register operations, I/O

### F3: Jump Format (32 bits)
```
| opcode (6) | address (26) |
```
Used for: unconditional jump (JSR)

## Full Instruction Set

### Arithmetic (int)
| Mnemonic | Format | Description |
|----------|--------|-------------|
| `ADD` | F2 | R[a] = R[b] + R[c] |
| `ADDI` | F1 | R[a] = R[b] + imm |
| `SUB` | F2 | R[a] = R[b] - R[c] |
| `SUBI` | F1 | R[a] = R[b] - imm |
| `MUL` | F2 | R[a] = R[b] * R[c] |
| `MULI` | F1 | R[a] = R[b] * imm |
| `DIV` | F2 | R[a] = R[b] / R[c] |
| `DIVI` | F1 | R[a] = R[b] / imm |
| `MOD` | F2 | R[a] = R[b] % R[c] |
| `MODI` | F1 | R[a] = R[b] % imm |
| `POW` | F2 | R[a] = R[b] ^ R[c] |
| `POWI` | F1 | R[a] = R[b] ^ imm |
| `CMP` | F2 | R[a] = sign(R[b] - R[c]) → -1, 0, 1 |
| `CMPI` | F1 | R[a] = sign(R[b] - imm) |

| Mnemonic | Format | Description |
|----------|--------|-------------|
| `fADD` | F2 | fR[a] = fR[b] + fR[c] |
| `fADDI` | F1 | fR[a] = fR[b] + fp16(imm) |
| `fSUB` | F2 | fR[a] = fR[b] - fR[c] |
| `fSUBI` | F1 | fR[a] = fR[b] - fp16(imm) |
| `fMUL` | F2 | fR[a] = fR[b] * fR[c] |
| `fMULI` | F1 | fR[a] = fR[b] * fp16(imm) |
| `fDIV` | F2 | fR[a] = fR[b] / fR[c] |
| `fDIVI` | F1 | fR[a] = fR[b] / fp16(imm) |
| `fMOD` | F2 | fR[a] = fR[b] % fR[c] |
| `fMODI` | F1 | fR[a] = fR[b] % fp16(imm) |
| `fCMP` | F2 | Float comparison → -1, 0, 1 |
| `fCMPI` | F1 | Float comparison with FP16 imm |

### Logical
| Mnemonic | Format | Description |
|----------|--------|-------------|
| `OR` | F2 | R[a] = R[b] \| R[c] |
| `ORI` | F1 | R[a] = R[b] \| imm |
| `AND` | F2 | R[a] = R[b] & R[c] |
| `ANDI` | F1 | R[a] = R[b] & imm |
| `BIC` | F2 | R[a] = R[b] & ~R[c] |
| `BICI` | F1 | R[a] = R[b] & ~imm |
| `XOR` | F2 | R[a] = R[b] ^ R[c] |
| `XORI` | F1 | R[a] = R[b] ^ imm |
| `LSH` | F2 | R[a] = R[b] << R[c] |
| `LSHI` | F1 | R[a] = R[b] << imm |
| `ASH` | F2 | R[a] = R[b] >> R[c] (arithmetic) |
| `ASHI` | F1 | R[a] = R[b] >> imm |

### Memory
| Mnemonic | Format | Description |
|----------|--------|-------------|
| `LDW` | F1 | R[a] = M[(R[b] + imm) / 4] |
| `LDX` | F2 | R[a] = M[(R[b] + R[c]) / 4] |
| `POP` | F1 | R[a] = M[R[b] / 4]; R[b] += imm |
| `STW` | F1 | M[(R[b] + imm) / 4] = R[a] |
| `STX` | F2 | M[(R[b] + R[c]) / 4] = R[a] |
| `PSH` | F1 | R[b] += imm; M[R[b] / 4] = R[a] |
| `ARRCPY` | F2 | Copy c words from M[R[b]:] to M[R[a]:] |

### Control Flow
| Mnemonic | Format | Description |
|----------|--------|-------------|
| `BEQ` | F1 | if R[a] == 0: PC += imm |
| `BNE` | F1 | if R[a] != 0: PC += imm |
| `BLT` | F1 | if R[a] < 0: PC += imm |
| `BGE` | F1 | if R[a] >= 0: PC += imm |
| `BLE` | F1 | if R[a] <= 0: PC += imm |
| `BGT` | F1 | if R[a] > 0: PC += imm |
| `BSR` | F1 | R[31] = PC+1; PC += imm (branch to subroutine) |
| `JSR` | F3 | R[31] = PC+1; PC = addr/4 (jump to subroutine) |
| `RET` | F2 | if c==0: halt; else: PC = c/4 |

### I/O
| Mnemonic | Format | Description |
|----------|--------|-------------|
| `RDI` | F2 | R[a] = read_int() |
| `RDF` | F2 | fR[a] = read_float() |
| `RDB` | F2 | R[a] = read_bool() ? 1 : 0 |
| `WRI` | F2 | print(R[b]) |
| `WRF` | F2 | printf("%.2f", fR[b]) |
| `WRB` | F2 | print(R[b] == 1) |
| `WRL` | F1 | println() |

## FP16 Encoding

F1-format float instructions use **half-precision (FP16)** for the immediate
field. The DLX emulator includes FP16 ↔ FP32 conversion routines:

- 1 sign bit, 5 exponent bits (bias 15), 10 mantissa bits
- Subnormal, normal, infinity, and NaN handling
- Round-to-nearest on FP32 → FP16 conversion

## Assembly API (Java)

```java
// F1: op a b imm
DLX.assemble(DLX.ADDI, dst, src, immediate);

// F1 with float immediate: op a b fp16
DLX.assemble(DLX.fADDI, dst, src, floatValue);

// F2: op a b c
DLX.assemble(DLX.ADD, dst, src1, src2);

// F1 branch: op a 0 offset
DLX.assemble(DLX.BEQ, reg, offset);

// F3 jump: op addr
DLX.assemble(DLX.JSR, address);

// No-arg (WRL only):
DLX.assemble(DLX.WRL);

// Single arg (RET, I/O):
DLX.assemble(DLX.RET, returnReg);
DLX.assemble(DLX.WRI, srcReg);
```

# Functions

## Declaration Syntax

```ebnf
funcDecl = "function" ident formalParam ":" ( "void" | type ) funcBody .
funcBody = "{" { varDecl } statSeq "}" ";" .
formalParam = "(" [ paramDecl { "," paramDecl } ] ")" .
paramDecl = paramType ident .
paramType = type { "[" "]" } .
```

### Basic Function

```coco
function add(int a, int b) : int {
    return a + b;
};
```

### Void Function

```coco
function greet() : void {
    call printInt(42);
    call println();
    return;
};
```

## Calling Functions

All function calls require the `call` keyword:

```coco
// Calling user-defined functions
result = call add(3, 4);        // as expression (non-void)
call greet();                    // as statement (void)

// Calling built-in functions
x = call readInt();              // as expression
call printInt(x);                // as statement
```

### Call Rules

| Call Context | Return Type | Valid? |
|-------------|-------------|--------|
| `x = call f()` (expression) | Non-void | Yes |
| `x = call f()` (expression) | `void` | **Type error** |
| `call f();` (statement) | `void` | Yes |
| `call f();` (statement) | Non-void | **Type error** |

### Arguments in Calls

```coco
call myFunc(42);                   // literal arg
call myFunc(x + y);                // expression arg
call myFunc(call readInt());       // function call result as arg
call myFunc(a, b, c);              // multiple args
call myFunc(arr[0], matrix[1][2]); // array element as arg
```

## Function Overloading

Functions are identified by **name + parameter types** (the *signature*).
Return type does not distinguish overloads.

```coco
function process(int x) : int {
    return x * 2;
};

function process(int x, int y) : int {  // OK — different arity
    return x + y;
};

function process(bool x) : int {        // OK — different param type
    if (x) then return 1; fi;
    return 0;
};

// function process(int x) : float {    // ERROR — same signature
//     return x * 1.5;
// };

main {
    a = call process(5);        // calls process(int) → int
    b = call process(5, 10);    // calls process(int,int) → int
    c = call process(true);     // calls process(bool) → int
}.
```

Overload resolution matches argument types exactly. No implicit coercion is
performed.

## Recursion

Recursive functions are fully supported:

```coco
function factorial(int n) : int {
    if (n <= 1) then return 1; fi;
    return n * call factorial(n - 1);
};
```

Mutual recursion works through forward references — functions can call
functions declared later in the source:

```coco
function foo(int x) : int {
    return call bar(x);     // bar is not yet declared — OK
};

function bar(int y) : int {
    return y * 2;
};
```

## Scope in Functions

- **Parameters** are local to the function
- **Local variables** declared inside the function body shadow globals and parameters
- **Global variables** are accessible in function bodies (read and write)
- Functions can shadow built-in functions by re-declaring with the same name

```coco
main
int globalVar;

function test(int param) : int {
    int localVar;           // local to test
    localVar = param + globalVar;  // access param and global
    return localVar;
};
{ ... }.
```

## Parameter Types

### Value Parameters (Scalars)

```coco
function f(int x, float y, bool z) : void { ... };
```

### Array Parameters

Array parameters use empty brackets — the size is not part of the type:

```coco
function sum(int[] arr) : int {
    int total; int i;
    i = 0;
    while (i < call length(arr)) do
        total = total + arr[i];
        i++;
    od;
    return total;
};
```

Note: There is no built-in `length` function for arrays — the above is
illustrative of array parameter syntax.

## Return Statement Rules

- `void` functions: `return;` or implicit return at end of body
- Non-`void` functions: `return expr;` where `expr` type matches declared return type
- Returning the wrong type is a compile error
- All code paths in a non-void function must return a value (not enforced by the
  type checker in the reference implementation, but a complete compiler should)

```coco
function abs(int x) : int {
    if (x < 0) then return -x; fi;
    return x;
};
```

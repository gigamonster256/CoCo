# Type System

CoCo is statically typed with **no implicit coercion** between types. Every
operator has a strict type signature, and type mismatches are caught at
compile time.

## Primitive Types

| Type    | Domain                           | Notes                     |
| ------- | -------------------------------- | ------------------------- |
| `int`   | 32-bit signed integer            | All arithmetic supported  |
| `float` | 32-bit IEEE 754 single precision | All arithmetic supported  |
| `bool`  | `true` or `false`                | Boolean logic only        |
| `void`  | No value                         | Function return type only |

## Operator Type Signatures

### Arithmetic

| Op  | Operand Types   | Result  |
| --- | --------------- | ------- |
| `+` | `int × int`     | `int`   |
| `+` | `float × float` | `float` |
| `-` | `int × int`     | `int`   |
| `-` | `float × float` | `float` |
| `*` | `int × int`     | `int`   |
| `*` | `float × float` | `float` |
| `/` | `int × int`     | `int`   |
| `/` | `float × float` | `float` |
| `%` | `int × int`     | `int`   |
| `%` | `float × float` | `float` |
| `^` | `int × int`     | `int`   |
| `^` | `float × float` | `float` |

**Cross-type operations are errors:** `int + float`, `float * int`, etc.
produce a compile-time `TypeError`.

### Boolean

| Op    | Operand Types | Result       |
| ----- | ------------- | ------------ |
| `and` | `bool × bool` | `bool`       |
| `or`  | `bool × bool` | `bool`       |
| `not` | `bool`        | `bool`       |
| `^`   | `bool × bool` | `bool` (xor) |

### Relational

| Input Types     | Valid Operators             | Result |
| --------------- | --------------------------- | ------ |
| `int × int`     | `==` `!=` `<` `<=` `>` `>=` | `bool` |
| `float × float` | `==` `!=` `<` `<=` `>` `>=` | `bool` |
| `bool × bool`   | `==` `!=`                   | `bool` |

Mixing types in comparisons (e.g., `bool == int`) is a type error.

### Assignment

| LHS     | Valid RHS                             |
| ------- | ------------------------------------- |
| `int`   | `int`                                 |
| `float` | `float`                               |
| `bool`  | `bool`                                |
| `T[N]`  | `T[N]` (same base type and dimension) |

Compound assignment operators (`+=`, `-=`, `*=`, etc.) follow the corresponding
binary operator type rules.

### Unary

| Op   | Valid Operands | Result          |
| ---- | -------------- | --------------- |
| `++` | `int`, `float` | Same as operand |
| `--` | `int`, `float` | Same as operand |

`++` and `--` are **not allowed** on `bool`.

## Array Types

```ebnf
ArrayType = BaseType "[" size "]" { "[" size "]" } .
```

- 0-indexed
- Dimensions are part of the type: `int[3]` ≠ `int[5]`
- Multi-dimensional: `int[2][3]` is array of 2 arrays of 3 ints each
- Array indexing requires `int` expression
- Compile-time bounds checking for constant indices
- Array parameter syntax: `int[]` (size not part of param type)

## Function Types

Function identity is determined by **name + parameter types** (not return type):

```coco
function f(int x) : int { ... };      // f(int)
function f(int x, int y) : int { ... }; // f(int,int) — OK, different arity
function f(bool x) : int { ... };     // f(bool) — OK, different param type
function f(int x) : float { ... };    // ERROR — same signature as first
```

## Common Type Errors

| Error                     | Example                     |
| ------------------------- | --------------------------- |
| `int + bool`              | `call printInt(1 + false);` |
| `bool` condition required | `while (42) do ... od;`     |
| `bool` used in arithmetic | `call printInt(3 - true);`  |
| Assigning wrong type      | `int x; x = 3.14;`          |
| `void` in expression      | `a = call println();`       |
| Non-`void` as statement   | `call readInt();`           |
| Increment `bool`          | `b++; // where b is bool`   |

## Type Checking Rules (Formal)

```
Γ ⊢ e1 : int    Γ ⊢ e2 : int
――――――――――――――――――――――――――
    Γ ⊢ e1 + e2 : int

Γ ⊢ e : bool
――――――――――――――
Γ ⊢ not e : bool

Γ ⊢ cond : bool    Γ ⊢ body ✓
――――――――――――――――――――――――――
Γ ⊢ while cond do body od ✓

Γ ⊢ lhs : τ    Γ ⊢ rhs : τ    τ.assign(τ) ✓
――――――――――――――――――――――――――――――――――
    Γ ⊢ lhs = rhs ✓
```

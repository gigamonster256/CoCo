# Interactive Playground

Try CoCo code directly in your browser. Type or paste CoCo source code below
and click **Run** to execute it.

<CoCoPlayground />

## How It Works

The playground includes a complete CoCo interpreter written in JavaScript:

- **Scanner** — tokenizes your source code
- **Parser** — builds an AST via recursive descent
- **Evaluator** — tree-walk interpreter with scoped variable storage

Supported features: arithmetic, boolean logic, comparisons, `if/then/else/fi`,
`while/do/od`, `repeat/until`, `++`/`--`, compound assignment, and built-in I/O
(`printInt`, `printFloat`, `printBool`, `println`).

## Example Programs

### Hello World
```coco
main {
    call printInt(42);
    call println();
}.
```

### Fibonacci via while loop
```coco
main {
    n = 10;
    a = 0;
    b = 1;
    i = 0;
    while (i < n) do
        call printInt(a);
        tmp = a + b;
        a = b;
        b = tmp;
        i++;
    od;
    call println();
}.
```

### Arithmetic precedence
```coco
main {
    call printInt(1 + 2 * 3 ^ 4);  // 163
    call println();
}.
```
